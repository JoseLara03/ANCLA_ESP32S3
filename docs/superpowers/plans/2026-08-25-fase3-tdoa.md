# Fase 3 — TDoA: blink, backhaul de timestamps y solve en el gateway

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Que 100 tags reporten posición a 5 Hz simultáneamente, emitiendo un
blink que la infraestructura estampa y el gateway resuelve, en lugar de que cada
tag haga TWR contra cuatro anclas y resuelva por su cuenta.

**Architecture:** El tag emite un frame `0xF0` BLINK en su slot y no espera nada.
Cada ancla que lo oye lee `dwt_readrxtimestamp()`, lo convierte al tiempo del
master con `sync_model_to_master()` y publica `(tag, seq, anchor, t_dtu)` por
MQTT. El gateway se suscribe a ese tópico, agrupa las observaciones del mismo
blink, y resuelve la posición por multilateración hiperbólica sobre las
*diferencias* de tiempo. Río abajo del solver nada cambia: sigue produciendo un
`struct pos_result` y publicándose por `pos_sink_publish()`.

**Tech Stack:** C99 puro para toda la matemática (host-testable con gcc, sin
Zephyr y sin CMSIS); Zephyr 4.4.x + MQTT para el backhaul; DW3220 vía el módulo
vendorizado.

**Spec:** `docs/superpowers/specs/2026-08-25-rtls-scale-tdoa-design.md` §4.3 y
Fase 3 de §5.

### Estado del gate: CORRIÓ, y falló contra su umbral original (2026-08-27)

Números medidos, de `docs/anchor-sync-measurement.md` §4.1 y de la fila "Gate de
Fase 2" de `docs/superpowers/specs/2026-08-25-rtls-scale-tdoa-design.md`:

| Distancia ancla-ancla | Jitter por observación | Veredicto contra 1 ns | Error de posición implicado |
|---|---|---|---|
| 30 cm | **782 ps** | `marginal` | ~0.23 m |
| 3 m | **1.44–1.53 ns** | **`fail`** | ~0.43–0.46 m |

La conversión es la del propio `tdoa_solve.h`: 1 ns son 64 DTU y
`TDOA_M_PER_DTU` = 4.69175e-3 m, o sea ~30 cm de error de camino por ns.
1.53 ns × 0.2998 m/ns = **0.459 m**.

**La Fase 3 está autorizada de todas formas**, porque el usuario **re-derivó
conscientemente el objetivo de exactitud del producto de 10–30 cm a ~45 cm** y el
peor caso medido cae justo en ese número. Es decir: la condicionalidad de las
tareas 5–6 está **resuelta, no pendiente** — pero resuelta por una **decisión de
producto**, no porque el hardware haya alcanzado el umbral que se le pidió. Dos
consecuencias que ninguna tarea de abajo puede ignorar:

- **No queda margen de sincronía para gastar.** Cualquier cosa que degrade el
  jitter (subir el intervalo entre CCPs, perder CCPs, re-baselinear el modelo)
  sale directamente del presupuesto de exactitud del producto. La escalera de
  remedios de §5 de `docs/anchor-sync-measurement.md` sigue siendo trabajo
  pendiente, no opcional, si el error medido en vivo supera los ~45 cm.
- **Ningún fix de la Fase 3 debe presentarse como mejor de lo que es.** En
  particular `out->residual_m` de `tdoa_solve()` es cero por construcción con 3
  anclas (ver su header), así que no sirve como señal de calidad para justificar
  nada.

Qué depende de qué, actualizado:

| Tareas | Dependen del gate | Estado |
|---|---|---|
| **1–4** | **No** | Matemática y formato de aire puros. Hechas y revisadas (1–3) / en curso (4). |
| 4B | No (es MAC, no sincronía) | **NO ESPECIFICADA.** Stub honesto abajo; hay que diseñarla antes de implementarla. |

**Prerrequisito de hardware que sí sigue abierto y bloquea 5–6 en el banco:**
un gateway alimentado por LiPo de 3.6 V **no emite un segundo frame por
superframe** — emite beacons y ningún CCP; con USB-C emiten los dos. Es caída de
alimentación bajo el consumo del PA en una ráfaga de doble TX de ~289 us, y es un
problema de hardware (ver el hecho ganado a pulso en `CLAUDE.md`). Sin CCPs no
hay `sync_model` válido, y sin `sync_model` válido `blink_rx` descarta **todas**
las observaciones (Tarea 5, Paso 7). **El gateway va con USB-C mientras la
alimentación del PA no esté corregida.** Del mismo modo, las anclas de la Fase 3
publican por WiFi, así que son nodos alimentados por red, no por batería.

## Global Constraints

Copiados literalmente del spec y de `CLAUDE.md`; aplican a **todas** las tareas.

- **PHY congelado:** canal 5, PLEN_1024, PAC32, código 9, 850 kbps, SFD_IEEE_4Z,
  STS y PDoA off. Ninguna tarea lo toca. Cambiarlo invalida la calibración de
  retardo de antena de toda la flota.
- **`src/uwb_frame_802_15_4z.{c,h}` y `src/cal_math.{c,h}` son byte-idénticos
  con `tag_testting`.** El BLINK **no** va ahí — módulo propio, como
  `apos_frame.c` y `ccp_frame.c`. Verificar con `diff` antes de cerrar cualquier
  tarea que los toque; debe salir vacío.
- **Contabilidad de longitudes: los bytes EXCLUYEN el FCS**, igual que
  `UWB_FRAME_LEN_*`. `dwt_getframelength()` y `cb_data->datalength` lo
  **incluyen**; los validadores usan `len >=`, no `len ==`.
- **El loop del gateway corre en `K_PRIO_COOP(0)`.** Nada en esa ruta puede
  bloquear ni esperar sin cota. Ninguna escritura a flash sin gate de
  presupuesto.
- **Toda comparación entre timestamps debe ser diferencia con signo.** El
  contador hi32 da la vuelta cada ~17.2 s y el de 40 bits también.
- **Sin float en rutas de tiempo/scheduling.** El solver sí usa float (como el
  del tag); la conversión de reloj es entera.
- Host tests: `gcc -Wall -Wextra -Isrc`, un `main()` por suite, `CHECK()`,
  salida distinta de cero al fallar. `-lm` solo donde se use `<math.h>`.
- Mensajes de commit terminan con
  `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`.

## Task 1: Formato de aire del BLINK

**Files:**
- Create: `src/blink_frame.h`, `src/blink_frame.c`
- Test: `tests/blink_frame/test_blink_frame.c`
- Modify: `CMakeLists.txt` (añadir `src/blink_frame.c` en orden alfabético)

**Interfaces:**
- Consumes: nada.
- Produces: `BLINK_FRAME_TYPE` (`0xF0`), `BLINK_FRAME_LEN` (`14`),
  `struct blink_frame { uint16_t src_addr; uint8_t seq; uint8_t batt_soc; uint8_t flags; }`,
  `int blink_frame_build(uint8_t *buf, size_t buf_len, uint16_t src_addr, uint8_t frame_seq, const struct blink_frame *f)`,
  `bool blink_frame_is_blink(const uint8_t *buf, size_t len)`,
  `int blink_frame_parse(const uint8_t *buf, size_t len, struct blink_frame *out)`.

**Layout** (offsets absolutos; longitud excluye FCS):

```
0..9    header 802.15.4: 0x41 0x88, seq, PANID 0xCA 0xDE, dest 0xFFFF, src, type 0xF0
10      blink_seq   monotónico, da la vuelta en 256; la clave de agrupación
11      batt_soc    0..100, o UWB_FRAME_POS_SOC_UNKNOWN (0xFF)
12      flags       bit0 = ALERT pendiente; bits 1..7 reservados, deben ser 0
13      reserved    debe ser 0; existe para que la longitud sea par
```

```c
#define CHECK(c) do { if (!(c)) { \

/* El código de función es un valor de AIRE asignado entre dos repos. Fijado

static void test_roundtrip(void)

    struct blink_frame in = { .seq = 0x5A, .batt_soc = 77, .flags = 0x01 };
    struct blink_frame out;

    CHECK(buf[2] == 0x22);
    CHECK(buf[3] == 0xCA && buf[4] == 0xDE);
    CHECK(buf[5] == 0xFF && buf[6] == 0xFF);
    CHECK(buf[7] == 0x01 && buf[8] == 0x01);
    CHECK(buf[9] == BLINK_FRAME_TYPE);
    CHECK(buf[13] == 0);

    CHECK(blink_frame_is_blink(buf, sizeof(buf)));
    CHECK(blink_frame_parse(buf, sizeof(buf), &out) == 0);

/* Igual que ccp_frame: dwt_getframelength() INCLUYE el FCS, así que un test
 * `len ==` tiraría todo frame real de un llamador que no lo restó. */
static void test_length_tolerates_the_fcs(void)
{
    uint8_t buf[BLINK_FRAME_LEN + 2];
    struct blink_frame in = { .seq = 1, .batt_soc = 50, .flags = 0 };

    CHECK(blink_frame_build(buf, sizeof(buf), 1, 0, &in) > 0);
    CHECK(blink_frame_is_blink(buf, BLINK_FRAME_LEN));
    CHECK(blink_frame_is_blink(buf, BLINK_FRAME_LEN + 2));
    CHECK(!blink_frame_is_blink(buf, BLINK_FRAME_LEN - 1));
}

/* Los bits reservados deben ser cero. Aceptarlos hoy hace imposible usarlos
 * mañana sin romper compatibilidad. */
static void test_reserved_bits_rejected(void)
{
    uint8_t buf[BLINK_FRAME_LEN];
    struct blink_frame in = { .seq = 1, .batt_soc = 50, .flags = 0 };
    struct blink_frame out;

    CHECK(blink_frame_build(buf, sizeof(buf), 1, 0, &in) > 0);
    buf[12] = 0x02;
    CHECK(blink_frame_parse(buf, sizeof(buf), &out) == -EPROTO);
    buf[12] = 0x00;
    buf[13] = 0x01;
    CHECK(blink_frame_parse(buf, sizeof(buf), &out) == -EPROTO);
}

static void test_rejects_other_codes(void)
{
    uint8_t buf[BLINK_FRAME_LEN];
    struct blink_frame in = { .seq = 1, .batt_soc = 0, .flags = 0 };
    struct blink_frame out;
    const uint8_t others[] = { 0xE0, 0xE5, 0xEA, 0xEB, 0xEE, 0xEF };

    CHECK(blink_frame_build(buf, sizeof(buf), 1, 0, &in) > 0);
    for (unsigned int i = 0; i < sizeof(others); i++) {
        buf[9] = others[i];
        CHECK(!blink_frame_is_blink(buf, sizeof(buf)));
        CHECK(blink_frame_parse(buf, sizeof(buf), &out) == -EINVAL);
    }
}

static void test_arg_checks(void)
{
    uint8_t buf[BLINK_FRAME_LEN];
    struct blink_frame in = { .seq = 1, .batt_soc = 0, .flags = 0 };

    CHECK(blink_frame_build(NULL, sizeof(buf), 1, 0, &in) == -EINVAL);
    CHECK(blink_frame_build(buf, sizeof(buf), 1, 0, NULL) == -EINVAL);
    CHECK(blink_frame_build(buf, BLINK_FRAME_LEN - 1, 1, 0, &in) == -EMSGSIZE);
    CHECK(!blink_frame_is_blink(NULL, BLINK_FRAME_LEN));
}

static void test_airtime(void)
{
    const unsigned int us = 1042 + 8 + 22 + (BLINK_FRAME_LEN + 2) * 941 / 100;

    CHECK(us > 1200 && us < 1250);
    printf("  BLINK airtime: ~%u us; 500/s = %.1f %% de ocupacion\n",
           us, (double)us * 500.0 / 10000.0);
}

int main(void)
{

    test_length_tolerates_the_fcs();

    test_arg_checks();
    test_airtime();

    printf("blink_frame: ALL TESTS PASSED\n");
    return EXIT_SUCCESS;
}
```

- [ ] **Step 4: Escribir la implementación mínima**

Crear `src/blink_frame.c`, copiando el estilo de `src/ccp_frame.c` (helpers
little-endian propios; no exportar internos del codec compartido).

```c
#include "blink_frame.h"
#include <errno.h>

#define OFF_SEQ_HDR 2u
#define OFF_DEST    5u
#define OFF_SRC     7u
#define OFF_TYPE    9u
#define ADDR_BCAST  0xFFFFu

static void put_u16(uint8_t *p, uint16_t v)
{
    p[0] = (uint8_t)v;
    p[1] = (uint8_t)(v >> 8);
}

static uint16_t get_u16(const uint8_t *p)
{
    return (uint16_t)(p[0] | ((uint16_t)p[1] << 8));
}

int blink_frame_build(uint8_t *buf, size_t buf_len, uint16_t src_addr,
                      uint8_t frame_seq, const struct blink_frame *f)
{
    if (!buf || !f) return -EINVAL;
    if (buf_len < BLINK_FRAME_LEN) return -EMSGSIZE;

    buf[0] = 0x41;
    buf[1] = 0x88;
    buf[OFF_SEQ_HDR] = frame_seq;
    buf[3] = 0xCA;
    buf[4] = 0xDE;
    put_u16(&buf[OFF_DEST], ADDR_BCAST);
    put_u16(&buf[OFF_SRC], src_addr);
    buf[OFF_TYPE] = BLINK_FRAME_TYPE;

    buf[BLINK_OFF_SEQ]   = f->seq;
    buf[BLINK_OFF_SOC]   = f->batt_soc;
    buf[BLINK_OFF_FLAGS] = (uint8_t)(f->flags & ~BLINK_FLAG_RESERVED_MASK);
    buf[BLINK_OFF_RSVD]  = 0;
    return (int)BLINK_FRAME_LEN;
}

bool blink_frame_is_blink(const uint8_t *buf, size_t len)
{
    return buf && len >= BLINK_FRAME_LEN && buf[0] == 0x41 && buf[1] == 0x88 &&
           buf[3] == 0xCA && buf[4] == 0xDE && buf[OFF_TYPE] == BLINK_FRAME_TYPE;
}

int blink_frame_parse(const uint8_t *buf, size_t len, struct blink_frame *out)
{
    if (!out) return -EINVAL;
    if (!blink_frame_is_blink(buf, len)) return -EINVAL;
    if (buf[BLINK_OFF_FLAGS] & BLINK_FLAG_RESERVED_MASK) return -EPROTO;
    if (buf[BLINK_OFF_RSVD] != 0) return -EPROTO;

    out->src_addr = get_u16(&buf[OFF_SRC]);
    out->seq      = buf[BLINK_OFF_SEQ];
    out->batt_soc = buf[BLINK_OFF_SOC];
    out->flags    = buf[BLINK_OFF_FLAGS];
    return 0;
}
```

## Task 3: El solver TDoA

El núcleo matemático de la Fase 3, y es un **cambio de modelo de medición sobre
la misma maquinaria**, no un rewrite.

**Files:**
- Create: `src/tdoa_solve.h`, `src/tdoa_solve.c`
- Test: `tests/tdoa_solve/test_tdoa_solve.c`
- Modify: `CMakeLists.txt`, `CLAUDE.md`

**Interfaces:**
- Consumes: `struct pos_result` y `POS_MAX_ANCHORS` de `pos_solver.h` (Tarea 2).
- Produces: `TDOA_M_PER_DTU` (`4.69175e-3f`), `TDOA_MIN_ANCHORS` (`3`),
  `struct tdoa_meas { float x, y, dz; int64_t t_dtu; }`,
  `bool tdoa_solve(const struct tdoa_meas *m, size_t n, const float *seed_xy, struct pos_result *out)`.

**La matemática, para que el implementador no la derive mal.** Con el ancla 0
como referencia y `r_i(x,y) = sqrt((x−x_i)² + (y−y_i)² + dz_i²)`, cada ancla
`i ≥ 1` aporta una ecuación:

```
f_i(x, y) = ( r_i(x,y) − r_0(x,y) )  −  d_i
d_i       = (t_i − t_0) × TDOA_M_PER_DTU
∂f_i/∂x   = (x − x_i)/r_i − (x − x_0)/r_0
∂f_i/∂y   = (y − y_i)/r_i − (y − y_0)/r_0
```

`n` anclas dan `n−1` ecuaciones y hay 2 incógnitas: con 3 anclas queda
exactamente determinado, con 4 sobredeterminado. Las ecuaciones normales son
2×2 y se invierten en forma cerrada, **igual que en `pos_solver.c`** — copiar de
ahí el patrón de iteración, el test de determinante y los criterios de parada en
vez de inventarlos.

```c
static const float AX[4] = { 0.0f, 10.0f, 10.0f,  0.0f };
static const float AY[4] = { 0.0f,  0.0f, 10.0f, 10.0f };

 * enteros en DTU, como llegan del hardware, con un offset común arbitrario que
 * el solver debe cancelar -- ese es todo el punto de TDoA. */
static void make(struct tdoa_meas *m, size_t n, float tx, float ty,

{

        float dx = tx - AX[i], dy = ty - AY[i];

        m[i].x = AX[i];
        m[i].y = AY[i];
        m[i].dz = DZ;
        m[i].t_dtu = common_offset + (int64_t)llroundf(r / TDOA_M_PER_DTU);
    }
}
```

- [ ] **Step 4: Escribir la implementación**

Crear `src/tdoa_solve.c`. **Abrir `src/pos_solver.c` en paralelo**: los valores
de `MAX_ITER`, del epsilon de convergencia y del umbral de determinante deben
copiarse de ahí, no reinventarse — son constantes ya probadas en hardware y
divergir introduce diferencias sutiles de comportamiento entre los dos solvers.

```c
#include "tdoa_solve.h"
#include <math.h>

/* Copiar de src/pos_solver.c, no elegir de nuevo. */
#define MAX_ITER     12
#define CONV_EPS_M   1e-4f
#define DET_EPS      1e-9f

/* Distancia 3D del punto (x,y) al ancla i, con dz dentro del modelo. */
static float slant(const struct tdoa_meas *a, float x, float y)
{
    float dx = x - a->x, dy = y - a->y;

    return sqrtf(dx * dx + dy * dy + a->dz * a->dz);
}

/* RMS de f_i sobre las n-1 ecuaciones de diferencia, en metros.
 *
 * Deliberadamente NO usa pos_residual_rms(): aquel mide desacuerdo de RANGO
 * contra rangos medidos, y aqui no hay rangos medidos -- solo diferencias. Un
 * fix TDoA perfecto tiene residual de diferencia cero y un residual de rango
 * que no significa nada, porque el rango absoluto nunca se observo. */
static float diff_residual(const struct tdoa_meas *m, size_t n, float x, float y)
{
    float r0 = slant(&m[0], x, y);
    float acc = 0.0f;

    for (size_t i = 1; i < n; i++) {
        float d_meas = (float)(m[i].t_dtu - m[0].t_dtu) * TDOA_M_PER_DTU;
        float f = (slant(&m[i], x, y) - r0) - d_meas;

        acc += f * f;
    }
    return sqrtf(acc / (float)(n - 1));
}

bool tdoa_solve(const struct tdoa_meas *m, size_t n, const float *seed_xy,
                struct pos_result *out)
{
    if (!out) return false;

    out->valid = false;
    out->x = 0.0f;
    out->y = 0.0f;
    out->residual_m = 0.0f;
    out->n_used = 0;
    out->dropped_idx = POS_NO_DROP;

    if (!m || n < TDOA_MIN_ANCHORS || n > POS_MAX_ANCHORS) return false;

    float x, y;

    if (seed_xy) {
        x = seed_xy[0];
        y = seed_xy[1];
    } else {
        /* Centroide de las anclas: interior al casco convexo, que es donde la
         * geometria TDoA esta bien condicionada. Fuera de el las hiperbolas se
         * aplanan y la iteracion se va. */
        x = 0.0f;
        y = 0.0f;
        for (size_t i = 0; i < n; i++) { x += m[i].x; y += m[i].y; }
        x /= (float)n;
        y /= (float)n;
    }

    for (int it = 0; it < MAX_ITER; it++) {
        float jtj00 = 0.0f, jtj01 = 0.0f, jtj11 = 0.0f;
        float jtf0 = 0.0f, jtf1 = 0.0f;
        float r0 = slant(&m[0], x, y);

        /* dz distinto de cero mantiene r0 lejos de cero, pero un despliegue con
         * dz = 0 y el tag justo sobre el ancla lo alcanza. */
        if (r0 < 1e-6f) return false;

        for (size_t i = 1; i < n; i++) {
            float ri = slant(&m[i], x, y);

            if (ri < 1e-6f) return false;

            float d_meas = (float)(m[i].t_dtu - m[0].t_dtu) * TDOA_M_PER_DTU;
            float f  = (ri - r0) - d_meas;
            float gx = (x - m[i].x) / ri - (x - m[0].x) / r0;
            float gy = (y - m[i].y) / ri - (y - m[0].y) / r0;

            jtj00 += gx * gx;
            jtj01 += gx * gy;
            jtj11 += gy * gy;
            jtf0  += gx * f;
            jtf1  += gy * f;
        }

        /* Ecuaciones normales 2x2, invertidas en forma cerrada. Mismo patron
         * que pos_solver.c, y por la misma razon: es mas barato que una
         * inversion generica y deja probar el determinante explicitamente,
         * que es como se detecta la geometria degenerada (anclas colineales)
         * en vez de devolver un punto inventado. */
        float det = jtj00 * jtj11 - jtj01 * jtj01;

        if (fabsf(det) < DET_EPS) return false;

        float dx = -( jtj11 * jtf0 - jtj01 * jtf1) / det;
        float dy = -(-jtj01 * jtf0 + jtj00 * jtf1) / det;

        x += dx;
        y += dy;

        if (fabsf(dx) < CONV_EPS_M && fabsf(dy) < CONV_EPS_M) {
            out->x = x;
            out->y = y;
            out->residual_m = diff_residual(m, n, x, y);
            out->n_used = (uint8_t)n;
            /* El rechazo de outliers NO se porta aqui, deliberadamente. Con 3
             * anclas no hay redundancia que lo permita, y con 4 el criterio de
             * subconjuntos de pos_solve() hay que re-derivarlo para diferencias
             * antes de que signifique algo. Trabajo futuro, no olvido. */
            out->dropped_idx = POS_NO_DROP;
            out->valid = true;
            return true;
        }
    }
    return false;   /* no convergio */
}
```

## Task 4B: Acceso ranurado del BLINK y asignación implícita de slot — **NO ESPECIFICADA**

**Esta tarea está marcada explícitamente como NO ejecutable.** No tiene pasos con
código porque falta diseñarla, y fingir lo contrario sería peor que dejarla
abierta. Está aquí porque las dos decisiones que la motivan **ya están tomadas** y
no caben ni en la Tarea 5 ni en la Tarea 6: sin ella, la Fase 3 tiene camino de
observación y de solve, pero no tiene MAC para 100 tags.

### Lo que T4B necesita antes de poder escribirse (medido 2026-08-28)

Esta sección se escribió DESPUÉS de que la Tarea 7 pusiera el BLINK en el aire,
y cambia el tamaño de T4B: no es "elegir una constante de guarda", es mover el
instante de transmisión del tag a otra base de tiempo.

**Hallazgo 1 — el BLINK de hoy NO cobra el ahorro de airtime.**
`uwb_net_runner.c` lo emite en `ctx.tx_slot * (T_SLOT_MS + T_GUARD_MS)`, es
decir **la misma ranura que usaba el barrido TWR**: una trama de 1.223 ms
ocupando una ranura dimensionada para un intercambio de 13.32 ms. Con
`UWB_FRAME_N_CFP` = 11 eso da 11 tags por superframe, exactamente los mismos
que TWR. El tag ahorra batería (transmite y duerme, en vez de cuatro
intercambios con RX abierto) pero **la red no gana capacidad**. El factor de
10.9x en airtime está sin cobrar, y cobrarlo ES la Tarea 4B.

**Hallazgo 2 — el bloqueo real es la base de tiempo, no la constante.**
El tag programa su ranura desde `t0_ms`, y `uwb_radio_now_ms()` es
`k_uptime_get_32()` (`uwb_net_runner.c:260-263`): el reloj del kernel, en
MILISEGUNDOS. Peor, `t0_ms` se muestrea por software DESPUÉS de salir del bucle
de RX del beacon (`:783`), no del timestamp de recepción del DW3000. Así que la
incertidumbre del instante de transmisión tiene tres términos y el primero
domina por dos órdenes de magnitud:

1. **Cuantización de milisegundos**: +/-1 ms, por construcción.
2. **Latencia software** entre el RMARKER del beacon y la llamada a
   `now_ms()`: variable, incluye lecturas SPI y validación de trama.
3. Deriva del cristal del tag entre el beacon y su ranura: ~8 us sobre un
   superframe a +/-20 ppm. Despreciable frente a los otros dos.

Lo que eso le hace a la capacidad, sobre los 152 ms de CFP:

| guarda | ranuras | condición |
|--------|---------|-----------|
| 2.0 ms | 47  | reloj de ms de hoy |
| 0.2 ms | 106 | TX diferido en DTU |
| 0.1 ms | 114 | DTU, guarda agresiva |

Es decir: **sobre el reloj de ms, T4B rinde ~4x en vez de ~10x**. La mitad de la
ganancia se va en guarda.

**Por lo tanto T4B empieza por mover el TX del BLINK a la base de tiempo del
DW3000** — un TX diferido programado desde el *timestamp de recepción del
beacon* en DTU, exactamente como `anchor_respond.c` programa su respuesta desde
`poll_rx_ts + turnaround`. Solo DESPUÉS de eso tiene sentido medir la
incertidumbre residual y derivar `BLINK_SLOT_GUARD_UUS` de ella.

**La trampa que ese cambio hereda, y que ya costó dos ciclos de banco en la
Fase 2**: el plazo de armado de un TX diferido es `DX_TIME - SHR`, no
`DX_TIME`. El RMARKER está al FINAL de su propio SHR, que a PLEN_1024 dura
1 050 194 ns. Medir la holgura contra el RMARKER en vez de contra el preámbulo
ocultó un fallo del 100% de los CCP durante dos sesiones. Cualquier BLINK
programado en DTU hereda exactamente ese plazo. Ver la entrada correspondiente
en `CLAUDE.md`.

**Hallazgo 3 — el beacon no puede llevar el mapa, y esto ya está decidido.**
`UWB_FRAME_LEN_BEACON` es `15 + 2 * UWB_FRAME_N_CFP`, así que un mapa explícito
crece dos bytes por ranura: 37 bytes con 11 ranuras, 243 con 114. La asignación
tiene que ser **implícita desde `seat_id`**, y `gw_core_build_slotmap()` (EDF
sobre 128 asientos, más los tiers FAST/SLOW/IDLE) ya hace la mayor parte del
trabajo. Nota de formato de onda: `UWB_FRAME_N_CFP` es un LITERAL en el cable,
así que cambiar el número de ranuras cambia la longitud del beacon y por tanto
**necesita subir `proto_ver`** — un tag viejo leería un beacon de otra longitud.

**Orden de trabajo sugerido, con lo que bloquea cada paso:**

1. Mover el TX del BLINK del tag a TX diferido en DTU desde el RX del beacon.
   *No bloqueado.* Es la precondición de todo lo demás.
2. Medir la incertidumbre residual del instante de transmisión, con sniffer o
   con un ancla instrumentada. **Esta es la medición que este documento venía
   pidiendo**, y solo es interpretable después del paso 1: hoy mediría la
   cuantización del reloj de ms, no la del hardware.
3. Derivar `BLINK_SLOT_GUARD_UUS` de esa medición y fijar el número de ranuras.
4. Asignación implícita de ranura desde `seat_id` en `gw_core`, y subir
   `proto_ver`.

**Lo que este análisis NO establece:** la cifra de 1.223 ms de airtime del BLINK
es una derivación de `mac_budget.h`, no una medición; los 64 us de jitter de
armado citados en otras partes se midieron en el ANCLA (ESP32-S3), no en el tag
(nRF52), y no se ha comprobado que transfieran; y nada de la Fase 3 se ha
verificado en hardware.

### Decisión 1 — el acceso es RANURADO, no aleatorizado

Tomada por el usuario, y la aritmética es la razón. Con acceso aleatorio sobre un
espacio de posiciones, la probabilidad de colisión por blink con 100 tags es:

| Posiciones del espacio aleatorio | P(colisión) por blink |
|---|---|
| 163 | **46 %** |
| 500 | 18 % |
| 1000 | 9 % |

Inaceptable a cualquier tamaño razonable. El ranurado funciona y por margen
amplio, porque **un blink cuesta 1.223 ms una sola vez y lo oyen todas las
anclas**, contra 4 × 3.33 = **13.32 ms** de un barrido TWR: **10.9× menos
airtime por fix**. Dentro de los mismos 146.5 ms que hoy ocupan los 11 slots de
ranging caben:

| Guarda por slot | Slots de blink en 146.5 ms |
|---|---|
| 0.1 ms | **110** |
| 0.3 ms | 96 |
| 0.5 ms | 85 |

y 100 tags a 5 Hz necesitan 100. **La guarda es el parámetro que decide** si el
objetivo de 100 tags entra o no.

**Entradas medidas para dimensionar la guarda** (esto es lo que falta cerrar):
el jitter de armado de TX del propio gateway, **64 us**, medido en hardware esta
semana, más ~**8 us** de deriva del cristal del tag sobre un superframe de 200 ms
a 40 ppm. Es decir el piso físico está muy por debajo de 0.1 ms; lo que falta es
decidir cuánto margen se le agrega por incertidumbre de recepción del beacon en
el tag y justificarlo, no adivinar un número.

### Decisión 2 — la asignación de slot es IMPLÍCITA; el beacon NO crece

El beacon **no puede** llevar un mapa a esta escala, y el número es exacto: el
mapa son 2 bytes por slot y `UWB_FRAME_LEN_BEACON` es
`15 + 2 × UWB_FRAME_N_CFP` = `15 + 22` = **37** = `UWB_FRAME_MAX_LEN`, ya al
límite. Un mapa de 100 slots serían **215 bytes**, por encima incluso del máximo
de 802.15.4.

La solución es `slot = f(seat_id, superframe_counter)`: **sin mapa y sin crecer el
beacon**. El tag ya recibe su `seat_id` en el GRANT de la Fase 1, y el beacon ya
lleva `counter`, así que las dos entradas de la función están en el aire hoy.

**Corolario que conviene decir en voz alta: buena parte de la MAC de la Fase 3 ya
existe y hay que REINTERPRETARLA, no reescribirla.** `gw_core_build_slotmap()` ya
hace EDF sobre los asientos, y los tiers FAST/SLOW/IDLE ya son exactamente una
tasa de blink. Lo que cambia es el significado de la salida, igual que cuando el
mapa pasó de tabla de propiedad a calendario en `proto_ver` 3.

### Lo que falta diseñar antes de que esto sea ejecutable

1. La forma concreta de `f(seat_id, sf_counter)` y su prueba de que ningún par de
   asientos activos colisiona en el mismo superframe con tiers mezclados.
2. El valor de `BLINK_SLOT_GUARD_UUS`, derivado de los 64 us + 8 us de arriba más
   el margen de incertidumbre de beacon en el tag, con la cuenta escrita.
3. Si esto obliga a mover `proto_ver` otra vez (el formato del beacon no cambia,
   pero el **significado** del mapa sí, y ése es exactamente el criterio que se
   usó la vez anterior).
4. Cómo convive la CAP (JOIN/GRANT/KEEPALIVE) con 100 slots de blink dentro de
   `T_SUPERFRAME_UUS`, contra el modelo de `src/mac_budget.h`.
5. Qué pasa con un tag cuyo lease expiró: hoy desaparece del mapa; con asignación
   implícita hay que decidir cómo se le dice que deje de emitir.

**No implementar esta tarea desde este documento.** Requiere su propio ciclo de

```c
/* Escáner mínimo, no un parser de JSON. Se justifica porque el productor es
 * pos_json_blink() en este mismo archivo y el formato está fijado por
 * tests/pos_json_blink/: traer cJSON al firmware por seis campos escalares
 * costaría flash y una dependencia para nada. Busca "clave": y devuelve el
 * primer carácter del valor, saltando una comilla de apertura si la hay. */
static const char *scan_value(const char *json, const char *key)
{
	char pat[16];
	const char *p;
	int n = snprintf(pat, sizeof(pat), "\"%s\":", key);

	if (n < 0 || (size_t)n >= sizeof(pat)) {
		return NULL;
	}
	p = strstr(json, pat);
	if (p == NULL) {
		return NULL;
	}
	p += (size_t)n;
	if (*p == '"') {
		p++;
	}
	return p;
}

static bool scan_u32(const char *json, const char *key, uint32_t *out)
{
	const char *p = scan_value(json, key);

	if (p == NULL || *p < '0' || *p > '9') {
		return false;
	}
	*out = (uint32_t)strtoul(p, NULL, 10);
	return true;
}

static bool scan_i64(const char *json, const char *key, int64_t *out)
{
	const char *p = scan_value(json, key);

	if (p == NULL) {
		return false;
	}
	if (*p != '-' && (*p < '0' || *p > '9')) {
		return false;
	}
	*out = (int64_t)strtoll(p, NULL, 10);
	return true;
}

int pos_json_blink(char *buf, size_t len, const struct pos_blink_obs *o)
{
	int n;

	if (buf == NULL || o == NULL) {
		return -1;
	}

	n = snprintf(buf, len,
		     "{\"a\":%u,\"t\":%u,\"s\":%u,\"ts\":\"%lld\",\"q\":%u,\"b\":%u}",
		     (unsigned int)o->anchor_id, (unsigned int)o->tag_addr,
		     (unsigned int)o->blink_seq, (long long)o->t_dtu,
		     (unsigned int)o->quality, (unsigned int)o->batt_soc);

	if (n < 0 || (size_t)n >= len) {
		return -1;
	}
	return n;
}

int pos_json_blink_parse(const char *buf, size_t len, struct pos_blink_obs *out)
{
	/* NUL-termina una copia acotada: el payload de MQTT no viene terminado,
	 * y strstr() sobre memoria sin terminar leería fuera de rango. */
	char scratch[POS_JSON_BLINK_MAX_LEN];
	uint32_t a, t, s, q, b;
	int64_t ts;

	if (buf == NULL || out == NULL) {
		return -1;
	}
	if (len == 0u || len >= sizeof(scratch)) {
		return -1;
	}
	memcpy(scratch, buf, len);
	scratch[len] = '\0';

	if (!scan_u32(scratch, "a", &a) || !scan_u32(scratch, "t", &t) ||
	    !scan_u32(scratch, "s", &s) || !scan_u32(scratch, "q", &q) ||
	    !scan_u32(scratch, "b", &b) || !scan_i64(scratch, "ts", &ts)) {
		return -1;
	}
	if (a > 0xFFu || t > 0xFFFFu || s > 0xFFu || q > 0xFFFFu || b > 0xFFu) {
		return -1;
	}
	/* t_dtu es un tiempo, nunca negativo. Un negativo aquí significa un
	 * publicador roto o un payload corrupto, no un dato utilizable. */
	if (ts < 0) {
		return -1;
	}

	out->anchor_id = (uint8_t)a;
	out->blink_seq = (uint8_t)s;
	out->batt_soc  = (uint8_t)b;
	out->tag_addr  = (uint16_t)t;
	out->quality   = (uint16_t)q;
	out->t_dtu     = ts;
	return 0;
}
```

Nota: `scratch` son 96 bytes en el stack de quien llame, que en el gateway es el
hilo de uplink (4096 B), no el loop del beacon. No moverlo al loop del gateway.

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 *
 * The anchor side of TDoA: stamp a tag's BLINK and hand the observation to the
 * uplink.
 *
 * This module holds no arithmetic of its own, deliberately -- the same split
 * ccp_slave.c makes. Everything that could be wrong about the clock conversion
 * lives in sync_model.c (pure C, host-tested); what lives here is the part a
 * host test cannot reach: a real RX timestamp from a real DW3220, and the
 * decision to DISCARD when the local clock cannot be expressed in the master's
 * time base.
 *
 * ---- No transmission, ever ------------------------------------------------
 *
 * A BLINK is answered by nothing. This module reads, converts and enqueues; it
 * never calls dwt_starttx() and never delays the caller. That is what makes it
 * survivable on hardware whose PA supply cannot sustain a second frame per
 * superframe (see CLAUDE.md): Phase 3 adds no UWB transmission to any node.
 *
 * ---- Discarding is the correct outcome, not a failure ---------------------
 *
 * sync_model_to_master() returns false whenever the model has no rate estimate
 * yet or has coasted past SYNC_MISS_MAX. An observation without a common time
 * base is NOISE, not data: fed to tdoa_solve() it would move the reported
 * position by however far the two anchors' clocks happen to be apart, and the
 * solver has no way to tell that from a real path difference. So it is dropped
 * and counted (blink_rx_stats()'s n_no_sync), never published with a local
 * timestamp and never published with a guessed one.
 */

#ifndef BLINK_RX_H
#define BLINK_RX_H

#include "uwb_config.h"

#include <stdbool.h>
#include <stdint.h>

/* Latch this anchor's id and clear the counters. Call once, before the SLAVE
 * loop starts, with the same config the rest of the loop uses. */
void blink_rx_init(const uwb_config_t *cfg);

/* Offer one received frame. Returns true if it WAS a BLINK -- consumed either
 * way, so the caller can stop its dispatch chain -- and false if the frame is
 * for someone else.
 *
 * `rx_ts` is the full 40-bit DW3220 RX timestamp, exactly as
 * uwb_get_rx_timestamp_u64() returns it. Do NOT shift it to hi32: sync_model
 * works in whole DTU and the bottom 8 bits are 255 DTU (~1.2 m of path
 * difference at TDOA_M_PER_DTU) -- the same rule ccp_slave_on_rx() states, and
 * it matters more here, since this timestamp goes straight into a position.
 *
 * `quality` is the CIR quality the caller already read; carried through as
 * diagnostics only. The solver does not use it. */
bool blink_rx_on_rx(const uint8_t *buf, uint16_t plen, uint64_t rx_ts,
		    uint16_t quality);

/* Counters. `n_rx` is BLINKs received, `n_no_sync` those dropped because
 * sync_model_to_master() refused, `n_bad` those that parsed as a BLINK type but
 * failed blink_frame_parse() (reserved bits set), and `n_sent` those handed to
 * the uplink. n_rx == n_no_sync with n_sent flat is the signature of a board
 * hearing tags fine while its CCP link is down -- check `sync stats` before
 * suspecting the radio. */
void blink_rx_stats(uint32_t *n_rx, uint32_t *n_no_sync, uint32_t *n_bad,
		    uint32_t *n_sent);

#endif /* BLINK_RX_H */
```

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 */

#include "blink_rx.h"

#include "blink_frame.h"
#include "ccp_slave.h"
#include "net_uplink.h"
#include "pos_json.h"
#include "sync_model.h"
#include "uwb_debug.h"

#include <zephyr/logging/log.h>

/* ANCLA_LOG_LEVEL, not LOG_LEVEL_INF: the per-BLINK verdict line below is the
 * only way to see WHY observations are not reaching the gateway, and an INF cap
 * would compile it out of reach of debug.conf. Still INF in production. */
LOG_MODULE_REGISTER(blink_rx, ANCLA_LOG_LEVEL);

/* Module state, static -- nothing on the stack. The SLAVE loop's stack is the
 * main stack (4096 B) and a 2588-byte automatic already overflowed it once. */
static uint8_t  my_anchor_id;
static uint32_t n_blink_rx;
static uint32_t n_blink_no_sync;
static uint32_t n_blink_bad;
static uint32_t n_blink_sent;

void blink_rx_init(const uwb_config_t *cfg)
{
	my_anchor_id     = (cfg != NULL) ? cfg->anchor_id : 0u;
	n_blink_rx       = 0u;
	n_blink_no_sync  = 0u;
	n_blink_bad      = 0u;
	n_blink_sent     = 0u;
}

bool blink_rx_on_rx(const uint8_t *buf, uint16_t plen, uint64_t rx_ts,
		    uint16_t quality)
{
	struct blink_frame bf;
	struct pos_blink_obs obs;
	uint64_t t_master;

	if (!blink_frame_is_blink(buf, plen)) {
		return false;
	}

	n_blink_rx++;

	if (blink_frame_parse(buf, plen, &bf) != 0) {
		n_blink_bad++;
		LOG_DBG("{\"blink\":{\"verdict\":\"malformed\"}}");
		return true;
	}

	/* The one place this module can refuse. ccp_slave_model() is const by
	 * contract -- this is a pure read of the live model, which is exactly
	 * what that constness is for. */
	if (!sync_model_to_master(ccp_slave_model(), rx_ts, &t_master)) {
		n_blink_no_sync++;
		LOG_DBG("{\"blink\":{\"tag\":\"0x%04X\",\"seq\":%u,"
			"\"verdict\":\"no sync -- dropped\"}}",
			bf.src_addr, bf.seq);
		return true;
	}

	/* t_master is a 40-bit DTU value in the master's base, so the cast to
	 * int64_t is lossless and cannot go negative. The signed type exists
	 * because tdoa_dtu_rebase() (Task 6) turns these into SIGNED
	 * differences on the gateway. */
	obs.anchor_id = my_anchor_id;
	obs.blink_seq = bf.seq;
	obs.batt_soc  = bf.batt_soc;
	obs.tag_addr  = bf.src_addr;
	obs.quality   = quality;
	obs.t_dtu     = (int64_t)t_master;

	net_uplink_submit_blink(&obs);
	n_blink_sent++;

	LOG_DBG("{\"blink\":{\"tag\":\"0x%04X\",\"seq\":%u,\"anchor\":%u,"
		"\"verdict\":\"stamped\"}}",
		bf.src_addr, bf.seq, my_anchor_id);
	return true;
}

void blink_rx_stats(uint32_t *n_rx, uint32_t *n_no_sync, uint32_t *n_bad,
		    uint32_t *n_sent)
{
	if (n_rx != NULL) {
		*n_rx = n_blink_rx;
	}
	if (n_no_sync != NULL) {
		*n_no_sync = n_blink_no_sync;
	}
	if (n_bad != NULL) {
		*n_bad = n_blink_bad;
	}
	if (n_sent != NULL) {
		*n_sent = n_blink_sent;
	}
}
```

```c
 *
 * Se llama desde mqtt_bring_up(), que es lo que hace que la RE-suscripción tras
 * una reconexión sea automática y no un caso especial olvidable: cada
 * reconexión pasa por aquí. Un gateway que reconecta sin re-suscribirse queda
 * SORDO en silencio -- sigue publicando fixes que ya no puede calcular, y nada
 * en el log lo dice.
 *

 * en un mqtt_abort() y un reintento con backoff. Deliberadamente NO se sigue
 * adelante sin suscripción: una conexión que publica pero no recibe es
 * exactamente el estado indetectable que este gate existe para evitar. */
static bool subscribe_observations(void)
{
	struct mqtt_topic topic = {
		.topic = {
			.utf8 = (uint8_t *)POS_JSON_TOPIC_BLINK,
			.size = sizeof(POS_JSON_TOPIC_BLINK) - 1u,
		},
		.qos = MQTT_QOS_0_AT_MOST_ONCE,
	};
	struct mqtt_subscription_list list = {
		.list        = &topic,
		.list_count  = 1u,
		.message_id  = next_msg_id++,
	};
	int ret;

	if (next_msg_id == 0u) {
		next_msg_id = 1u;
	}

	suback_seen = false;
	ret = mqtt_subscribe(&client, &list);
	if (ret != 0) {
		LOG_WRN("mqtt_subscribe failed (%d)", ret);
		n_obs_sub_fail++;
		return false;
	}

	/* Hasta 10 s, la misma escala que la espera de CONNACK. Acotado: este
	 * hilo es preemptible, pero un bucle sin cota aquí dejaría el uplink
	 * colgado para siempre sin decir por qué. */
	for (int i = 0; i < 100 && !suback_seen && mqtt_connected; i++) {
		struct zsock_pollfd fds = {
			.fd     = client.transport.tls.sock,
			.events = ZSOCK_POLLIN,
		};

		if (zsock_poll(&fds, 1, 100) > 0 && mqtt_input(&client) != 0) {
			break;
		}

	if (!suback_seen) {
		LOG_WRN("no SUBACK for %s within 10 s — the gateway would be "
			"deaf; reconnecting", POS_JSON_TOPIC_BLINK);
		n_obs_sub_fail++;
		return false;
	}

	LOG_INF("subscribed to %s", POS_JSON_TOPIC_BLINK);
	return true;
}
```

### El hallazgo que obliga a `tdoa_dtu`: el contador de 40 bits da la vuelta

`tdoa_solve()` trabaja con `t_i − t_0` y `struct tdoa_meas.t_dtu` es un
timestamp **absoluto** en la base del master, o sea un valor de 40 bits que
**da la vuelta cada ~17.2 s**. Si de las cuatro observaciones de un mismo blink
una cae del otro lado de la vuelta, su diferencia cruda contra la referencia es
del orden de 2^40 DTU = **~5.16 millones de kilómetros** de diferencia de
camino (1 099 511 627 776 × 4.69175e-3 m = 5.1586e9 m), y el
solver no tiene forma de saber que eso no es una medición: convergería (o no) y
en cualquier caso mentiría.

Ni `tdoa_collect` ni `tdoa_solve` lo arreglan y **no deben** arreglarlo: el
colector solo agrupa y el solver ya está entregado y probado con entradas
rebasadas. Así que la corrección va en un módulo propio, C puro y host-testeable,
que `tdoa_gw` aplica entre `tdoa_collect_take_ready()` y `tdoa_solve()`. Es la
regla global de este plan — **toda comparación entre timestamps es diferencia con
signo** — aplicada al módulo de 2^40 en vez de al de 2^32.

Y una vez rebasadas, hay una segunda cosa gratis: acotar la magnitud. Un despliegue
real tiene diferencias de camino de metros, no de kilómetros. `TDOA_DTU_MAX_SPREAD`
= 32768 DTU son **153.7 m** de diferencia de camino (32768 × 4.69175e-3).

**Es un margen deliberadamente generoso, no un número ajustado, y la potencia de
dos es por comodidad.** El despliegue que este proyecto persigue son cuatro
anclas en una zona del tamaño de una habitación — los surveys de `apos` medidos
hasta ahora dan aristas de **1.2 a 2.5 m**, y el máximo que este MAC podría
cubrir está en el orden de decenas de metros — así que la diferencia de camino
real entre dos anclas del mismo blink está acotada por la separación entre
anclas y vive en **metros de un dígito**. 154 m son entre uno y dos órdenes de
magnitud por encima de eso. Eso es intencional: el filtro NO pretende detectar un
error de sincronía de decímetros (para eso no hay instrumento aquí, y ése es
justo el error que el gate de Fase 2 mide), sino descartar el caso grosero — una
vuelta de 40 bits sin corregir, un `t_dtu` corrupto, un modelo de reloj
re-baselineado a mitad de un grupo. Apretarlo a, digamos, 20 m lo volvería un
filtro de calidad de sincronía disfrazado, con un umbral que nadie derivó. Si
alguna vez se quiere ese filtro, se deriva su umbral del jitter medido y va
aparte; no se reutiliza esta cota.

Nótese que **la cota NO se derivó de la magnitud de la vuelta** (5.16 millones de
km) sino de la física del despliegue: cualquier valor entre ~50 m y ~1 km habría
atrapado el artefacto de vuelta igual de bien, y por eso el error de tres órdenes
de magnitud que esta prosa tuvo antes no tocó el número. Es
el único filtro de cordura que existe antes del solver, y hace falta
precisamente porque el header de `tdoa_solve()` advierte dos cosas: con 3 anclas
el residual es cero por construcción, y la convergencia se juzga solo por tamaño
de paso, así que un tag fuera del casco puede asentarse en la rama espejo y
reportar `valid` estando mal. Un residual no puede filtrar nada de eso; una cota
física sí filtra el caso grosero.

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 *
 * Turn a group's ABSOLUTE 40-bit master-base timestamps into signed
 * differences, and bound them.
 *
 * struct tdoa_meas.t_dtu as it leaves blink_rx.c is an absolute DW3220
 * timestamp in the master's base: 40 bits, wrapping every ~17.2 s. tdoa_solve()
 * consumes only (t_i - t_0), so two observations of the SAME blink landing on
 * opposite sides of that wrap differ by ~2^40 DTU -- about 5.16 MILLION km of
 * path
 * difference -- and the solver has no way to tell that from a measurement.
 *
 * Neither tdoa_collect (which only groups) nor tdoa_solve (already delivered
 * and tested against rebased inputs) is the right place for this, so it lives
 * here: the project's global "every timestamp comparison is a signed
 * difference" rule, applied at modulo 2^40 instead of 2^32.
 *
 * Pure C, no Zephyr, host-tested in tests/tdoa_dtu/.
 */

#ifndef TDOA_DTU_H
#define TDOA_DTU_H

#include <stddef.h>
#include <stdbool.h>
#include <stdint.h>

#include "tdoa_solve.h"   /* struct tdoa_meas */

/* The DW3220 timestamp counter is 40 bits. */
#define TDOA_DTU_MODULO  (1LL << 40)

/* Largest |t_dtu| a rebased group may carry, INCLUSIVE. 32768 DTU x
 * TDOA_M_PER_DTU = 153.7 m of path difference: far above any cell this MAC can
 * cover (four anchors inside one 200 ms superframe's ranging budget) and far
 * below any wrap artefact or broken-sync value. This is the ONLY sanity filter
 * standing in front of the solver, and it is needed precisely because
 * tdoa_solve()'s own residual cannot be one -- it is zero by construction at
 * TDOA_MIN_ANCHORS, and convergence there is judged by step size only, so a
 * tag outside the anchor hull can settle on the mirror branch and still report
 * valid. A residual filters none of that; a physical bound filters the gross
 * case. */
#define TDOA_DTU_MAX_SPREAD  32768LL

/* Rebase every t_dtu on m[0].t_dtu, reducing modulo 2^40 into
 * [-2^39, 2^39) so the result is the SIGNED difference. m[0].t_dtu becomes 0.
 * Geometry fields (x, y, dz) are untouched. No-op for m == NULL or n == 0.
 *
 * Idempotent for an already-rebased group (m[0] is 0, so the base is 0). */
void tdoa_dtu_rebase(struct tdoa_meas *m, size_t n);

/* True when every |t_dtu| is <= TDOA_DTU_MAX_SPREAD. Call AFTER
 * tdoa_dtu_rebase(); on a raw group it will (correctly) reject anything that
 * crossed the wrap, which is the defence-in-depth that makes a forgotten
 * rebase visible instead of silent. False for m == NULL or n == 0. */
bool tdoa_dtu_plausible(const struct tdoa_meas *m, size_t n);

#endif /* TDOA_DTU_H */
```

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 */

#include "tdoa_dtu.h"

#define TDOA_DTU_HALF  (TDOA_DTU_MODULO / 2LL)

void tdoa_dtu_rebase(struct tdoa_meas *m, size_t n)
{
	int64_t base;
	size_t i;

	if (m == NULL || n == 0u) {
		return;
	}

	base = m[0].t_dtu;

	for (i = 0u; i < n; i++) {
		/* % en C trunca hacia cero, así que el resto puede salir
		 * negativo; se normaliza a [0, 2^40) y sólo entonces se pliega
		 * a [-2^39, 2^39). Hacerlo en un paso con % sobre un valor
		 * posiblemente negativo es exactamente el error que hace que
		 * esto funcione en un sentido de la vuelta y no en el otro. */
		int64_t d = (m[i].t_dtu - base) % TDOA_DTU_MODULO;

		if (d < 0) {
			d += TDOA_DTU_MODULO;
		}
		if (d >= TDOA_DTU_HALF) {
			d -= TDOA_DTU_MODULO;
		}
		m[i].t_dtu = d;
	}
}

bool tdoa_dtu_plausible(const struct tdoa_meas *m, size_t n)
{
	size_t i;

	if (m == NULL || n == 0u) {
		return false;
	}

	for (i = 0u; i < n; i++) {
		int64_t t = m[i].t_dtu;

		if (t > TDOA_DTU_MAX_SPREAD || t < -TDOA_DTU_MAX_SPREAD) {
			return false;
		}
	}
	return true;
}
```

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 *
 * The gateway side of TDoA: drain the anchors' observations, group them, solve,
 * and hand a struct pos_fix to pos_sink_publish().
 *
 * NOTHING DOWNSTREAM CHANGES. This module produces exactly the struct pos_fix
 * the 0xEA dispatch path in uwb_gateway.c already produces -- same Tid
 * derivation (gw_core_find_eui() + tag_id_from_eui()), same pos_sink_publish(),
 * same pos_json_fix() payload, same frozen contract with the customer platform.
 * The measurement model changed; the telemetry did not.
 *
 * ---- Bounded, and called from K_PRIO_COOP(0) ------------------------------
 *
 * tdoa_gw_step() runs on the loop that arms the beacon, where no lower-priority
 * thread -- including the shell -- can run while it spins, and where an
 * unbounded busy-wait once froze this board permanently. So it is bounded twice
 * over: at most TDOA_GW_INGEST_MAX observations folded in and at most
 * TDOA_GW_SOLVE_MAX solves per call, both constants and neither derived from
 * anything an anchor or a broker controls. It never blocks (net_uplink_get_obs()
 * is K_NO_WAIT), never transmits, and never writes flash.
 *
 * It is called ONCE PER SUPERFRAME, from the top of the gateway's outer loop --
 * i.e. just after a beacon has gone out, where nearly the whole superframe of
 * margin remains. Deliberately NOT from the inner RX loop: there it would run
 * hundreds of times per superframe for no gain, since observations arrive on the
 * uplink thread's cadence (POLL_TIMEOUT_MS, 50 ms) and not on RX events.
 *
 * ---- The thread boundary is the queue, so no lock exists here --------------
 *
 * MQTT PUBLISHes are parsed on the uplink thread (priority 10) and pushed into
 * net_uplink's obs_q; struct tdoa_collect is owned exclusively by THIS module,
 * touched only from tdoa_gw_step(), i.e. only from the gateway loop. That is
 * why there is no mutex anywhere in this path: the two threads share a
 * k_msgq and nothing else.
 */

#ifndef TDOA_GW_H
#define TDOA_GW_H

#include <stdint.h>

#include "gw_core.h"

/* Per-call bounds. INGEST_MAX x (one k_msgq_get + one linear scan of
 * TDOA_COLLECT_SLOTS) and SOLVE_MAX x (one Gauss-Newton solve over <= 4
 * anchors) are both tens of microseconds against BEACON_ARM_MARGIN_UUS
 * (5000 uus) -- and this runs a whole superframe away from the next arm, not
 * next to it. At 4 anchors x 5 Hz x 8 movers, 8 observations per superframe is
 * the steady-state arrival rate, so the bound throttles a burst rather than
 * the normal case. Raising either without re-reading the beacon heartbeat on
 * hardware is exactly the mistake CLAUDE.md's TX_COMPLETE_TIMEOUT_MS entries
 * document. */
#define TDOA_GW_INGEST_MAX  8u
#define TDOA_GW_SOLVE_MAX   2u

/* Clear the collector and every cache. Call once, before the gateway loop. */
void tdoa_gw_init(void);

/* Ingest up to TDOA_GW_INGEST_MAX observations and publish up to
 * TDOA_GW_SOLVE_MAX fixes. `ctx` is the live seat table, read-only, for the
 * EUI lookup that Tid needs; `now_ms` is k_uptime_get_32(). */
void tdoa_gw_step(const struct gw_core_ctx *ctx, uint32_t now_ms);

/* Counters, for `net show` and for the bench. `n_obs` are observations folded
 * into the collector, `n_reject` observations the collector REFUSED (a duplicate
 * anchor for a blink, or every slot already holding a releasable group -- see
 * tdoa_collect.h's slot-exhaustion note; a climbing n_reject is load shedding,
 * which otherwise looks exactly like anchors going quiet), `n_fix` fixes
 * published, `n_no_anchor` observations
 * dropped because no surveyed anchor matches their anchor_id, `n_implausible`
 * groups rejected by tdoa_dtu_plausible(), `n_solve_fail` groups tdoa_solve()
 * refused, and `n_jump` fixes rejected for moving impossibly far from a recent
 * previous fix for the same tag. */
void tdoa_gw_stats(uint32_t *n_obs, uint32_t *n_reject, uint32_t *n_fix,
		   uint32_t *n_no_anchor, uint32_t *n_implausible,
		   uint32_t *n_solve_fail, uint32_t *n_jump);

#endif /* TDOA_GW_H */
```

```c
/*
 * Copyright (c) 2026 Innovaforce
 *
 * SPDX-License-Identifier: Apache-2.0
 */

#include "tdoa_gw.h"

#include "apos_store.h"
#include "net_uplink.h"
#include "pos_json.h"
#include "pos_sink.h"
#include "pos_solver.h"
#include "tag_id.h"
#include "tdoa_collect.h"
#include "tdoa_dtu.h"
#include "tdoa_solve.h"
#include "uwb_config.h"
#include "uwb_debug.h"
#include "uwb_frame_802_15_4z.h"

#include <zephyr/kernel.h>
#include <zephyr/logging/log.h>

#include <math.h>

LOG_MODULE_REGISTER(tdoa_gw, ANCLA_LOG_LEVEL);

/* Per-tag memory: the seed for the next solve, the last known battery, and the
 * plausibility reference for the jump gate. Same order of magnitude as the
 * collector's slot count on purpose -- a tag with an open group is exactly a
 * tag that will want a seed. */
#define TDOA_GW_SEED_SLOTS   16u

/* A seed older than this is not evidence about where the tag is now. At 5 Hz a
 * live tag refreshes it every 200 ms, so 1 s is five missed blinks. */
#define TDOA_GW_SEED_AGE_MS  1000u

/* Largest jump accepted against a seed younger than TDOA_GW_SEED_AGE_MS.
 * 10 m in <= 1 s is 36 km/h: impossible for a person carrying a tag, and it is
 * the ONLY guard against the mirror-branch failure tdoa_solve.h warns about --
 * a tag outside the anchor hull can converge on the reflected solution and
 * still report valid = true, and its residual will not say so. Deliberately
 * generous: this rejects the branch flip (which lands metres away), not
 * ordinary noise. */
#define TDOA_GW_MAX_JUMP_M   10.0f

struct tag_memo {
	uint16_t tag_addr;
	float    x, y;
	uint32_t ms;
	uint8_t  batt_soc;
	bool     valid;
};

/* All module state static -- the gateway loop runs on the 4096-byte main stack
 * and a 2588-byte automatic silently overflowed it once (see CLAUDE.md). This
 * struct tdoa_collect alone is over 700 bytes. */
static struct tdoa_collect collect;
static struct tag_memo     memo[TDOA_GW_SEED_SLOTS];

static uint32_t n_obs_in;
static uint32_t n_add_reject;
static uint32_t n_fix_out;
static uint32_t n_no_anchor;
static uint32_t n_implausible;
static uint32_t n_solve_fail;
static uint32_t n_jump;

void tdoa_gw_init(void)
{
	tdoa_collect_init(&collect);
	memset(memo, 0, sizeof(memo));
	n_obs_in      = 0u;
	n_add_reject  = 0u;
	n_fix_out     = 0u;
	n_no_anchor   = 0u;
	n_implausible = 0u;
	n_solve_fail  = 0u;
	n_jump        = 0u;
}

/* Where anchor `anchor_id` is, from the applied survey.
 *
 * The survey is keyed by short address, and an anchor's short address is
 * UWB_ANCHOR_ADDR_BASE + anchor_id (the MAC contract reserves 0x0000 for the
 * gateway, which is why the console's 0-based id cannot go on the wire). An
 * unsurveyed gateway returns false for every anchor and therefore publishes no
 * fixes at all -- which is correct and is the same refusal
 * anchor_respond_wave_poll() makes: coordinates that were never measured
 * produce a confidently meaningless position. */
static bool anchor_xyz(uint8_t anchor_id, float *x, float *y, float *z)
{
	const struct apos_survey *s = apos_store_get();
	uint16_t want;
	uint8_t i;

	if (s == NULL || !s->valid || anchor_id >= UWB_MAX_ANCHORS) {
		return false;
	}

	want = (uint16_t)(UWB_ANCHOR_ADDR_BASE + anchor_id);

	for (i = 0u; i < s->n_nodes; i++) {
		if (s->node[i].short_addr == want) {
			*x = s->node[i].x;
			*y = s->node[i].y;
			*z = s->node[i].z;
			return true;
		}
	}
	return false;
}

static struct tag_memo *memo_find(uint16_t tag_addr)
{
	uint8_t i;

	for (i = 0u; i < TDOA_GW_SEED_SLOTS; i++) {
		if (memo[i].valid && memo[i].tag_addr == tag_addr) {
			return &memo[i];
		}
	}
	return NULL;
}

/* An entry for `tag_addr`: the existing one, a free slot, or the oldest one.
 * Never NULL.
 *
 * Evicting the OLDEST is right HERE and would be wrong in tdoa_collect -- do
 * not "unify" the two. This is a per-tag cache where every entry is equally
 * complete and age is the only signal of whether it still describes a live tag;
 * the collector's slots hold PARTIAL groups, where age correlates with being
 * closer to COMPLETE, so it evicts by completeness first and never evicts a
 * releasable group while a less-complete one exists (see its header's
 * slot-exhaustion note). Same words, opposite conclusion, different data. */
static struct tag_memo *memo_claim(uint16_t tag_addr, uint32_t now_ms)
{
	struct tag_memo *oldest = &memo[0];
	uint8_t i;

	for (i = 0u; i < TDOA_GW_SEED_SLOTS; i++) {
		if (memo[i].valid && memo[i].tag_addr == tag_addr) {
			return &memo[i];
		}
		if (!memo[i].valid) {
			memo[i].valid    = true;
			memo[i].tag_addr = tag_addr;
			memo[i].ms       = now_ms;
			memo[i].batt_soc = UWB_FRAME_POS_SOC_UNKNOWN;
			return &memo[i];
		}
		/* Signed difference: now_ms wraps freely. */
		if ((int32_t)(memo[i].ms - oldest->ms) < 0) {
			oldest = &memo[i];
		}
	}

	memset(oldest, 0, sizeof(*oldest));
	oldest->valid    = true;
	oldest->tag_addr = tag_addr;
	oldest->ms       = now_ms;
	oldest->batt_soc = UWB_FRAME_POS_SOC_UNKNOWN;
	return oldest;
}

/* One observation from the uplink into the collector. Returns false only when
 * the queue was empty, so the caller can stop early. */
static bool ingest_one(uint32_t now_ms)
{
	struct pos_blink_obs obs;
	struct tdoa_obs t;
	struct tag_memo *mm;
	float z = 0.0f;

	if (!net_uplink_get_obs(&obs)) {
		return false;
	}

	if (!anchor_xyz(obs.anchor_id, &t.meas.x, &t.meas.y, &z)) {
		n_no_anchor++;
		LOG_WRN("observation from anchor %u: not in the applied survey "
			"— dropped", obs.anchor_id);
		return true;
	}

	/* dz follows struct pos_meas's convention: anchor z minus TAG z, and
	 * the tag's z is unmeasured, so it is assumed 0 -- exactly the
	 * assumption the tag's own solver already makes with the coordinates
	 * a WAVE response carries. A survey run in APOS_GEOM_2D mode pins
	 * every z at 0 anyway, which is the deployment this project has. */
	t.meas.dz    = z;
	t.meas.t_dtu = obs.t_dtu;
	t.tag_addr   = obs.tag_addr;
	t.blink_seq  = obs.blink_seq;
	t.anchor_id  = obs.anchor_id;

	/* The battery reading rides on the observation, not on the group: the
	 * collector carries only struct tdoa_meas, so it is remembered here
	 * per tag and read back when the fix is built. */
	mm = memo_claim(obs.tag_addr, now_ms);
	mm->batt_soc = obs.batt_soc;

	if (tdoa_collect_add(&collect, &t, now_ms)) {
		n_obs_in++;
	} else {
		/* false is not only "duplicate anchor for this blink": since
		 * tdoa_collect's post-review revision it is also "every slot
		 * already holds a releasable group", where the collector
		 * REFUSES the new observation rather than destroying a fix that
		 * already exists. Counted, because a gateway shedding load that
		 * way otherwise looks identical to anchors that stopped
		 * publishing. */
		n_add_reject++;
	}
	return true;
}

/* One ready group into one published fix. Returns false when no group was
 * ready, so the caller can stop early. */
static bool solve_one(const struct gw_core_ctx *ctx, uint32_t now_ms)
{
	struct tdoa_meas m[POS_MAX_ANCHORS];
	struct pos_result res;
	struct pos_fix fix;
	struct tag_memo *mm;
	uint8_t eui[UWB_FRAME_EUI_LEN];
	const float *seed = NULL;
	float seed_xy[2];
	size_t n = 0u;
	uint16_t tag_addr = 0u;

	if (!tdoa_collect_take_ready(&collect, now_ms, m, &n, &tag_addr)) {
		return false;
	}

	/* Absolute 40-bit timestamps in, signed differences out. Must happen
	 * before the solver sees them and before the plausibility test. */
	tdoa_dtu_rebase(m, n);

	if (!tdoa_dtu_plausible(m, n)) {
		n_implausible++;
		LOG_WRN("blink from 0x%04X: implausible spread — dropped "
			"(broken sync, or a wrap this rebase did not fix)",
			tag_addr);
		return true;
	}

	mm = memo_find(tag_addr);
	if (mm != NULL && (int32_t)(now_ms - mm->ms) <
			  (int32_t)TDOA_GW_SEED_AGE_MS) {
		seed_xy[0] = mm->x;
		seed_xy[1] = mm->y;
		seed = seed_xy;
	}

	if (!tdoa_solve(m, n, seed, &res) || !res.valid) {
		n_solve_fail++;
		LOG_WRN("blink from 0x%04X: solve failed over %u anchors",
			tag_addr, (unsigned int)n);
		return true;
	}

	/* The mirror-branch gate. tdoa_solve()'s header says outright that a
	 * tag outside the anchor hull can converge on the reflected solution
	 * and still report valid, and that its residual is too weak to tell --
	 * zero by construction at n == 3. A recent previous fix is the
	 * corroboration that header asks for. */
	if (seed != NULL) {
		float dx = res.x - seed_xy[0];
		float dy = res.y - seed_xy[1];

		if (sqrtf(dx * dx + dy * dy) > TDOA_GW_MAX_JUMP_M) {
			n_jump++;
			LOG_WRN("blink from 0x%04X: fix (%.2f, %.2f) jumps "
				"more than %.1f m from the last one — dropped",
				tag_addr, (double)res.x, (double)res.y,
				(double)TDOA_GW_MAX_JUMP_M);
			return true;
		}
	}

	mm = memo_claim(tag_addr, now_ms);
	mm->x  = res.x;
	mm->y  = res.y;
	mm->ms = now_ms;

	fix.src_addr   = tag_addr;
	fix.x          = res.x;
	fix.y          = res.y;
	fix.residual_m = res.residual_m;
	fix.n_anchors  = res.n_used;
	fix.batt_soc   = mm->batt_soc;

	/* Identical Tid derivation to the 0xEA path in uwb_gateway.c, including
	 * the fallback and its cost: a straggler whose seat expired gets
	 * tag_id = src_addr and shows on the platform as a one-record phantom
	 * device. Documented and accepted there; unchanged here on purpose --
	 * two different derivations of Tid would be a worse bug than the
	 * phantom. */
	if (gw_core_find_eui(ctx, tag_addr, eui)) {
		fix.tag_id = tag_id_from_eui(eui, UWB_FRAME_EUI_LEN);
	} else {
		LOG_WRN("TDoA fix from 0x%04X: no live seat, Tid falls back to "
			"short address", tag_addr);
		fix.tag_id = tag_addr;
	}

	pos_sink_publish(&fix);
	n_fix_out++;
	return true;
}

void tdoa_gw_step(const struct gw_core_ctx *ctx, uint32_t now_ms)
{
	unsigned int i;

	for (i = 0u; i < TDOA_GW_INGEST_MAX; i++) {
		if (!ingest_one(now_ms)) {
			break;
		}
	}

	for (i = 0u; i < TDOA_GW_SOLVE_MAX; i++) {
		if (!solve_one(ctx, now_ms)) {
			break;
		}
	}
}

void tdoa_gw_stats(uint32_t *n_obs, uint32_t *n_reject, uint32_t *n_fix,
		   uint32_t *no_anchor, uint32_t *implausible,
		   uint32_t *solve_fail, uint32_t *jump)
{
	if (n_obs != NULL)       { *n_obs = n_obs_in; }
	if (n_reject != NULL)    { *n_reject = n_add_reject; }
	if (n_fix != NULL)       { *n_fix = n_fix_out; }
	if (no_anchor != NULL)   { *no_anchor = n_no_anchor; }
	if (implausible != NULL) { *implausible = n_implausible; }
	if (solve_fail != NULL)  { *solve_fail = n_solve_fail; }
	if (jump != NULL)        { *jump = n_jump; }
}
```
